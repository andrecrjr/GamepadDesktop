A FEW GOOD QUESTIONS

Before you settle in.

Is Gamepad Desktop free?

Yes. It is free and open source under the MIT License. You can inspect the source on GitHub.

Does it add controller support to games?

It controls the desktop using mouse and keyboard input. Native controller support inside a game is handled by the game itself.

Which controller can I use?

Select a controller recognized by the app. If yours needs a mapping, you can import an SDL controller mapping in the app's settings.

Can I adjust how the pointer feels?

Yes. Adjust pointer speed and deadzone in Settings. You can also change the interface size. The app saves your preferences for the next session.

How does the on-screen keyboard work?

Windows uses the system touch keyboard. Linux/X11 uses the app's keyboard; on Wayland, support depends on your compositor, with COSMIC keyboard integration when available. The app's keyboard is unavailable on GNOME Wayland. See the keyboard guide for your setup.
